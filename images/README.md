## Notes

- The set is intentionally small: logo, client logos, homepage imagery, service imagery, and project-card imagery.
- Use `home/hero-infraestructura-taludes.jpeg` as the primary homepage hero image.
- Use `brand/felfer-logo.png` for header/footer branding.
- Use the service folder matching each route slug.
- Use the project images only on `/proyectos`; the spec does not include individual project pages in v1.
- Some project images from the live site are visually reused across project entries, so avoid making unsupported public claims from images alone.
